# Headless CMS Roadmap Specifications (For Future Reference)

This file stores details for the upcoming Headless CMS module. Do not implement in the current phase.

## 1. Homepage & Sections CMS
* **Hero Section**: Title, Subtitle, Description, CTA Buttons, Background Image, Video, Overlay, Sort Order, Active.
* **Homepage Sections**: Enable/Disable flags & Sort order for Featured Products, Collections, Testimonials, Our Story, Featured Categories, Instagram Feed, FAQs, Newsletter, Brands, Services.
* **Banners**: Desktop Image, Mobile Image, Title, Subtitle, Button text/URL, Start/End dates, Priority, Active.

## 2. Navigation & Static Pages
* **Static Pages**: Rich text content, Slug, Visibility, SEO tags (About, Privacy, Terms, Shipping, Leather Care, Contact, FAQ).
* **Navigation Menu**: Hierarchical dropdown controls (Label, URL, parent, displayOrder, icon, visible).
* **Footer**: Links, Social Accounts, Contact Info, Copyright.

## 3. General CMS Modules
* **Testimonials**: Customer, Rating, Comment, Avatar, Visible, Display Order.
* **FAQ Management**: Question, Answer, Category, Display Order, Published.
* **Announcement Bar**: Text, Start/End dates, Priority scheduler.
* **Social Media & Contact details**: Phone, Email, Whatsapp, Address, Hours, OG Tags.
* **Newsletter & Media Library**: Subscriber list with CSV exporter, Media Library files manager.
* **CMS Versioning**: Draft/Published version states, Publisher log.
